# RaySC-V
A Custom RV32IM Processor with Hardware-Accelerated Ray Tracing.

独自命令拡張および専用アクセラレータを備えた RV32IM コアと専用コンパイラの協調設計．

## プロジェクトの目標

本プロジェクトでは，汎用的なRV32I基本命令を拡張し，コンパイラと自作プロセッサ・アクセラレータの協調設計による以下の段階的な高速化と定量的評価を目的とする．

1. RV32I: ベースライン
2. RV32M拡張: 単一サイクル乗算器およびマルチサイクル除算実装による高速化
3. 独自拡張命令: 平方根・3Dベクトル内積演算命令など(予定)
4. 専用アクセラレータ: 光線と物体の交差判定などを担う専用ハードウェアユニットの接続

評価は，命令数・サイクル数・動作周波数・回路規模(LUT・DSP)で行い，速さと回路規模のトレードオフを見る．

## 仕様上の決定事項(仮)

- BRAM: `0x00000000` - `0x0003FFFF` (256KB，初期スタックポインタ `sp` = `0x00040000`)
- 非整列アクセスは非対応(riscv-tests の `ma_data` は対象外)．`lh/lhu/sh` は2バイト境界，`lw/sw` は4バイト境界のアドレスのみ使う．アラインの保証はコンパイラ・アセンブラ側で行う
- 独自命令は `custom-0`(opcode `0x0B`)を使う
- MMIO アドレス: UART `0x10000000`，サイクルカウンタ `0x20000000`，アクセラレータ `0x30000000`


## ディレクトリ構成

- `compiler/`: OCaml自作コンパイラ(独自言語 Simple → RV32IM，独自命令のコード生成)
- `hw/`: RV32IM CPU コアおよび専用アクセラレータ回路(SystemVerilog)
- `sw/`: レイトレーサー(C版・自作言語版)
- `bsp/`: ベアメタル実行基盤(リンカスクリプト，スタートアップコード)
- `tests/`: 動作検証用コードおよびベンチマークプログラム
